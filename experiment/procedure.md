<h2>Actual vs Virtual Reality Lab Procedure</h2>

<h3 style="text-decoration:none;">1. Layout Planning :</h3>

<b>Actual (Traditional Architecture/Design)</b><br>
Draft the initial 2D floor plan and elevation blueprints to scale on paper or in a CAD program. Calculate room areas and clearances (e.g., minimum door widths).<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user enters the virtual environment where foundational walls, doors, and windows are already modeled (as shown in the video).

<hr>

<h3 style="text-decoration:none;">2. Scale Visualization :</h3>

<b>Actual (Traditional Architecture/Design)</b><br>
Build a physical scale model (e.g., 1:50 or 1:100) to visualize the space, or present the design via 2D plans and rendered images to the client/jury.<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user moves through the virtual house in 1:1 scale using VR locomotion or teleporting (indicated by pink lines), immediately experiencing room dimensions, ceiling height, and natural light penetration.

<hr>

<h3 style="text-decoration:none;">3. Functional Placement (Furniture) :</h3>

<b>Actual (Traditional Architecture/Design)</b><br>
Use paper cutouts or CAD blocks representing furniture (sofa, table, bed) and fit them onto the 2D plan, relying on imagination for 3D visualization.<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user virtually grabs and drags furniture items (bed, sofa, or table cards) and places them in the space, directly checking clearances, walk paths, and sightlines.

<hr>

<h3 style="text-decoration:none;">4. Design Modification / Testing :</h3>

<b>Actual (Traditional Architecture/Design)</b><br>
After physical model inspection, the architect must re-draft plans or rebuild the physical scale model to move walls or doorways (time-consuming).<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user teleports to a configuration menu (like the table with Japanese text) to instantly resize walls, change materials, or modify doors and see updates immediately.

<hr>

<h3 style="text-decoration:none;">5. Specialized System Check :</h3>

<b>Actual (Traditional Architecture/Design)</b><br>
Use separate methods to calculate plumbing flow (toilet/tub) or lighting efficiency across different zones.<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user triggers interactive systems (like the “PUSH ME” button on the virtual toilet or faucet) to visualize functionality or view embedded data (e.g., water flow simulation).

<hr>

<h3 style="text-decoration:none;">6. Final Review & Documentation :</h3>

<b>Actual (Traditional Architecture/Design)</b><br>
Generate final blueprints. The client/jury must infer the final aesthetic and spatial feel from flat paper drawings.<br><br>

<b>Virtual Reality (VR) Lab Procedure</b><br>
The user generates a virtual walkthrough or video recording and exits the lab with an immediate, immersive understanding of the final design.
